# 跑步姿态系统 — 腿部传感器扩展计划

## 最终架构：3+3 全无线（6 块 S3）

```
                   每侧 3 块 S3（左侧 + 右侧，完全镜像）

  肘部 S3 (现有,重烧)        大腿 S3 (新烧)         腰间 S3 (新烧)
  ┌─────────────────┐    ┌─────────────────┐    ┌─────────────────┐
  │ UART→上下臂JY901S │    │ UART→大腿小腿JY901S│    │ ESP-NOW RX ← 肘 │
  │ BLE Client→鞋垫   │    │ ESP-NOW TX ──────▶│    │ ESP-NOW RX ← 腿 │
  │ ESP-NOW TX ──────▶│    │                 │    │ BLE Server→电脑  │
  └─────────────────┘    └─────────────────┘    └─────────────────┘
     上臂/手肘绑带          大腿绑带 (有UART线)        腰间 (USB供电)
        ↑                                        ↑
        ESP-NOW 无线 ──────────────────────────────┘

  💡 腰包挂充电宝 → USB 供腰间 S3，不通宵跑步不用担心续航
  💡 肘部/大腿 S3 用纽扣锂电池
```

## 每侧 3 块 S3 职责总览

| 位置 | 数量 | 角色 | 物理接线 | 改动 |
|---|---|---|---|---|
| **肘部** | 1 | 手臂采集 | UART ×2 → 上臂/下臂 JY901S + BLE Client → 压力鞋垫 | **重烧**：去掉 BLE Server，加 ESP-NOW TX |
| **大腿** | 1 | 腿部采集 | UART ×2 → 大腿/小腿 JY901S | **新烧**：ESP-NOW TX |
| **腰间** | 1 | 纯汇聚 | 无传感器线 | **新烧**：ESP-NOW RX ×2 + BLE Server |

## 数据包 V2

V2 data 数组 (30 元素):
```
[0-2]   右/左大臂 roll/pitch/yaw  ← 肘部发来
[3-5]   右/左小臂 roll/pitch/yaw  ← 肘部发来
[6-8]   右/左大腿 roll/pitch/yaw  ← 大腿发来
[9-11]  右/左小腿 roll/pitch/yaw  ← 大腿发来
[12-29] 18 区足底压力             ← 肘部发来(压力鞋垫)
```

RG 包格式变化：

| | V1 (当前) | V2 |
|---|---|---|
| 角度 | 6 | 12 |
| 压力 | 18 | 18 |
| 载荷长度 | 48 字节 | 60 字节 |
| 包总长 | 56 字节 | 68 字节 |
| 版本号 | 1 | 2 |

## 改动文件清单

### 硬件固件（3 份）

**1. `rgc-backend/rgc-backend.ino`** — 肘部 S3（修改）
- 删除 BLE Server 相关代码
- 新增 ESP-NOW 初始化 + 发送回调（每 30ms 发手臂 6 角度 + 压力 18 区）
- 新增 BLE 命令接收（接收腰间发来的 RESET 指令）
- 手臂 IMU 采集代码一行不动

**2. `rgc-backend/satellite-leg/satellite-leg.ino`** — 大腿 S3（新建）
- 2 路 JY901S UART 解析（0x55 0x53 协议）
- 零偏校准（启动时采样 10 帧求均值）
- ESP-NOW 每 30ms 发送 6 角度
- 通过 `#define LEFT` / `#define RIGHT` 区分左右

**3. `rgc-backend/hub-waist/hub-waist.ino`** — 腰间 S3（新建）
- ESP-NOW 接收：肘部(手臂+压力) + 大腿(腿部角度)
- 组装 V2 RG 包（12 角度 + 18 压力）
- BLE Server 发给电脑
- 可选：接收来自电脑的 RESET 命令 → ESP-NOW 转发给肘部和大腿

### Python 后端

**4. `ble_bridge_launcher.py`** — 修改 `parse_rg_packet()`
- 按 payload_len 自动识别版本
- 48 字节 → V1: 手臂 6 角度 + 18 压力（腿部填 0）
- 60 字节 → V2: 12 角度 + 18 压力
- 前端收到的 `msg.data` 统一为 30 元素数组

### 前端（5 个页面）

**5. `js/index.js`** — 主页：适配 30 元素数组，新增腿部角度概览
**6. `js/arm.js`** — 关节曲线页：新增 4 条腿部 Chart.js 曲线
**7. `js/foot.js`** — 足底压力页：数据长度校验 24→30
**8. `threeDimention.html`** — 3D 姿态：新增腿部骨骼驱动 + 4 个关节标记球
**9. `report.html`** — 分析报告：新增腿部姿态章节

## 穿戴步骤（跑步前 2 分钟）

1. ✅ 腰包挂好，充电宝插腰间 S3
2. ✅ 肘部绑带 (手臂不动)，按一下开关 → 灯亮
3. ✅ 大腿绑带，按一下开关 → 灯亮，小腿 IMU 线沿腿走到膝盖下

5. ✅ 电脑打开 bat 启动
6. ✅ 开跑
