## 二、接线（肘部 & 大腿完全一致）

每块卫星 ESP32 接 2 颗 JY901S。**JY901S 由 GPIO 引脚直接供电，不走 3V3。**

| ESP32 引脚 | 连接 | 说明 |
|---|---|---|
| GPIO 1 | 上段 JY901S GND | OUTPUT LOW |
| GPIO 2 | 上段 JY901S TX | UART1 RX |
| GPIO 3 | 上段 JY901S RX | UART1 TX |
| GPIO 4 | 上段 JY901S VCC | OUTPUT HIGH |
| GPIO 9 | 下段 JY901S GND | OUTPUT LOW |
| GPIO 10 | 下段 JY901S TX | UART2 RX |
| GPIO 11 | 下段 JY901S RX | UART2 TX |
| GPIO 12 | 下段 JY901S VCC | OUTPUT HIGH |

### 上下段通过引脚区分

```
GPIO 2/3  (UART1)  → 上段（大臂 / 大腿）
GPIO 10/11 (UART2) → 下段（前臂 / 小腿）
```

接线时记住：**2-3 上，10-11 下。**

### LEFT 侧唯一区别

LEFT 侧固件设置 `#define LEFT`，UART 分配交换：

```
LEFT: 上段 → GPIO 10/11，下段 → GPIO 2/3
RIGHT: 上段 → GPIO 2/3，下段 → GPIO 10/11
```

**物理接线完全不变，只改固件里的 `#define`。**

## 三、烧录（共 6 次，先 Hub 后卫星）

### 环境

- Arduino IDE → 开发板选 **ESP32S3 Dev Module**
- 波特率 115200
- 所有库已内置（BLEDevice, WiFi, esp_now, HardwareSerial），无需安装

### 第一轮：烧录腰间 Hub（2 块）

| 步骤 | 操作 |
|------|------|
| 1 | 打开 `rgc-backend/hub-waist/hub-waist.ino` |
| 2 | 改 `#define LEFT` 或 `#define RIGHT` |
| 3 | 工具 → **USB CDC On Boot → Enabled** |
| 4 | 编译 → 烧录 → **拔插 USB 冷启动** |
| 5 | 运行以下命令自动读 MAC 并写入卫星固件： |

```bash
python tests/read_hub_mac.py
```

脚本自动检测 COM7，读 MAC，写入肘部和大腿固件的 `WAIST_MAC[]`。

> 若 COM 口不是 7：`python tests/read_hub_mac.py COM6` 手动指定。

另一块 Hub 改 `#define` 再烧一次。

### 第二轮：烧录卫星（4 块）

| 固件文件 | 烧录 2 次 | 编译选项 |
|----------|-----------|----------|
| `rgc-backend/rgc-backend.ino` | LEFT + RIGHT | USB CDC On Boot → **Disabled** |
| `rgc-backend/satellite-leg/satellite-leg.ino` | LEFT + RIGHT | USB CDC On Boot → **Disabled** |

每次烧录：改 `#define` → 确认 `WAIST_MAC[]` 已更新 → 上传 → 拔插冷启动。

卫星 USB CDC 关掉，它们靠纽扣电池运行，不接电脑。

## 四、安装穿戴

### 4.1 组装

```
肘部 ESP32 ─┬─ 短线 → 上臂 IMU（贴大臂中段外侧）
            └─ 长线 → 下臂 IMU（贴前臂中段外侧）
            
大腿 ESP32 ─┬─ 短线 → 大腿 IMU（贴大腿中段外侧）
            └─ 长线 → 小腿 IMU（贴小腿中段外侧）

腰间 Hub → USB 线接充电宝 → 塞腰包
```

ESP32 和 IMU 都用弹力绑带固定在肢体上。

### 4.2 佩戴原则

1. **IMU 有字面朝外**（和戴手表一样）
2. **贴肌肉中段**，不贴关节（关节皮肤会滑动）
3. **线往下走**，往肘/膝方向
4. **绑紧**，跑起来不松脱
5. **线留余量**，蹲下或屈膝时别拉断

### 4.3 鞋垫

直接塞鞋里，无接线，内置电池。通电后 BLE 广播有超时限制，长时间不用会休眠。

## 五、上电

**顺序随意。** 固件启动不依赖 IMU 数据，IMU、ESP32、鞋垫随便先后。

唯一注意：**卫星（肘部/腿部）用纽扣电池，不要插电脑 USB**。只有腰间 Hub 接电脑 USB。多块板子同时插电脑可能电涌。

## 七、校准

### 首次校准

1. 站直，手臂自然下垂，掌心朝内
2. 浏览器打开 `threeDimention.html`
3. 右侧控制面板点绿色 **「校准」** 按钮
4. 保持站姿 1 秒，完成

### 重校准（随时）

运动中感觉零点偏了 → 站好 → 点「校准」。不用断电，不用重启。

### 原理

```
前端校准按钮 → WebSocket → 桥接器 → BLE → Hub → ESP-NOW → 4 颗卫星
                                                        ↓
                                         采样 IMU 10 帧取平均 → 更新零点
```

## 十、故障排查

| 症状 | 原因 | 解决 |
|------|------|------|
| Hub 串口 `肘部: 无` | WAIST_MAC 填错 | 运行 `read_hub_mac.py` 重新读取并确认 |
| Hub 串口 `鞋垫: 无` | 鞋垫休眠 / MAC 不匹配 | 鞋垫重新上电 |
| BLE 连不上 | Hub 未冷启动 / USB CDC 冲突 | 拔插 Hub USB，关串口监视器 |
| arm.html 无数据 | WebSocket 8765 端口被占 | 重启 `一键启动.bat`（自带清理） |
| arm.html 只有一边 | 单 Hub 运行 | 正常，另一边没开 Hub 就空着 |
| USB 电涌 | 多块 S3 同时插电脑 | 卫星用电池，只有 Hub 接 USB |
| 压力曼陀罗全亮/全暗 | 归一化阈值不匹配 | 检查 `pressure-art.js` 的 `/50` 阈值 |
