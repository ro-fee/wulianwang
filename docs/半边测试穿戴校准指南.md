# 半边身体测试 — 穿戴、校准与接线指南

## 硬件清单（RIGHT 侧）

| 物料 | 数量 |
|------|------|
| ESP32-S3 SuperMini | 3 块 |
| JY901S IMU | 4 颗 |
| 压力鞋垫（右脚） | 1 只 |
| USB 充电宝 | 1 个 |
| 纽扣电池 | 2 个 |
| 弹力绑带 | 3 条 |

---

## 一、接线（肘部 & 腿部完全一致）

```
ESP32 引脚          连接

GPIO 1     JY901S GND（上段）— OUTPUT LOW
GPIO 2     上段 IMU TX → JY901S RX
GPIO 3     上段 IMU RX → JY901S TX
GPIO 4     JY901S VCC（上段）— OUTPUT HIGH

GPIO 9     JY901S GND（下段）— OUTPUT LOW
GPIO 10    下段 IMU TX → JY901S RX
GPIO 11    下段 IMU RX → JY901S TX
GPIO 12    JY901S VCC（下段）— OUTPUT HIGH
```

### 上下臂 / 大小腿通过引脚区分

```
接 GPIO 2/3 的 IMU  = 上段（大臂 / 大腿）→ 角度数组 [0-2]
接 GPIO 10/11 的 IMU = 下段（小臂 / 小腿）→ 角度数组 [3-5]
```

接线时就定死了，不需要贴标签。想验证：拔掉 GPIO 10/11，前端 `right_lower` 归零，`right_upper` 不受影响。

## 二、穿戴（约 2 分钟）

### 传感器位置

```
上臂 IMU —— 大臂外侧中段
  │ （短 UART 线）
  ├─ 肘部 ESP32 —— 大臂绑带固定
  │ （长 UART 线，沿手臂到前臂）
下臂 IMU —— 前臂外侧中段

大腿 IMU —— 大腿外侧中段
  │ （短 UART 线）
  ├─ 腿部 ESP32 —— 大腿绑带固定
  │ （长 UART 线，沿腿到小腿）
小腿 IMU —— 小腿外侧中段

腰间 Hub —— 腰包或腰挂 + USB 充电宝
鞋垫 —— 右脚鞋内
```

### 佩戴原则

1. **全朝外** — IMU 有字那面朝外，像戴手表
2. **贴中间** — 不贴关节，贴肌肉中段
3. **线朝下** — UART 线往肘/膝方向走
4. **绑紧不滑** — 弹力绑带固定，别留空隙

---

## 三、上电（顺序随意）

```
所有设备随便先后通电——IMU、ESP32、鞋垫、Hub 无所谓。
```

固件启动不再等 IMU 数据，通电即跑。

唯一注意：卫星（肘部/腿部）用纽扣电池，别插电脑 USB；只有 Hub 接电脑 USB。三块板子都插 USB 可能电涌。

---

## 四、校准

### 首次校准：每次上电后

1. 站直，手臂自然下垂，掌心朝内
2. 打开 `一键启动.bat`
3. 浏览器进入 3D 页面（`threeDimention.html`）
4. 打开右侧控制面板，点绿色 **「校准」** 按钮
5. 保持站姿 1 秒，校准完成

### 重校准：随时

运动中感觉零点偏了 → 站好姿势 → 点「校准」。不用断电，不用重启。

### 原理

```
前端校准按钮 → WebSocket → 桥接器 → BLE → Hub → ESP-NOW → 肘部 + 腿部
                                                        ↓
                                              采样 IMU 10 帧取平均作为零点
```

校准后所有角度 = 当前姿态 - 零点，即关节相对运动量。

### 主运动对应

| 关节 | 动作为 | 看哪个轴 |
|------|--------|----------|
| 肩屈伸 | 手臂前抬/后摆 | pitch（蓝色） |
| 肘屈伸 | 小臂弯/直 | pitch（蓝色） |
| 髋屈伸 | 大腿前抬/后蹬 | pitch（蓝色） |
| 膝屈伸 | 小腿弯/直 | pitch（蓝色） |
