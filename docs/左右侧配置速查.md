# 左右侧配置速查

> 2026-05-26 波特率验证 + 左侧配置

## MAC 地址

| 侧 | Hub WiFi MAC | C 数组 |
|---|---|---|
| 右 | `28:84:85:6D:68:0C` | `{0x28, 0x84, 0x85, 0x6D, 0x68, 0x0C}` |
| 左 | `28:84:85:6D:67:FC` | `{0x28, 0x84, 0x85, 0x6D, 0x67, 0xFC}` |

读取 MAC：`python tests/read_hub_mac.py COM<端口号>`（自动写入所有固件）

## 波特率

| 模块 | JY901S UART | Serial (USB) |
|---|---|---|
| 肘部 `rgc-backend.ino` | **9600** | 115200 |
| 腿部 `satellite-leg.ino` | **115200** | 115200 |
| 腰部 `hub-waist.ino` | —（不连 JY901S） | 115200 |

> 肘部 JY901S 尝试过改 115200 但 AT 指令未生效，保持原厂 9600。腿部 JY901S 为出厂默认 115200。

## 切换左右侧

三个固件各改一行：

```cpp
#define LEFT          // 启用
//#define RIGHT       // 注释掉
```

**同时需更新 `WAIST_MAC[]`** 为目标侧 Hub 的 MAC 地址。

### 当前状态 (2026-05-26)

所有固件当前为 **LEFT** 配置，MAC = `28:84:85:6D:67:FC`。

要切回右侧，需恢复：
1. `#define RIGHT`（三个文件）
2. `WAIST_MAC` = `{0x28, 0x84, 0x85, 0x6D, 0x68, 0x0C}`（肘部 + 腿部）

## 验证工具

| 工具 | 用途 |
|---|---|
| `tests/verify_imu.py` | 自动连 COM 口，dump ESP32 串口输出 |
| `tests/firmware/verify_jy901s/verify_jy901s.ino` | 读取并每秒打印 JY901S 角度，验证波特率 |
| `tests/read_hub_mac.py` | 读取 Hub MAC 并自动写入所有固件 |

### 验证 JY901S 波特率

1. 烧录 `verify_jy901s.ino`
2. `python tests/verify_imu.py`
3. 有角度数据 = 波特率正确，无数据 = 改 `BAUD` 重试

## 零偏校准

无线触发，全链路：`前端按钮 → WebSocket → Python → BLE → Hub → ESP-NOW → 卫星`

卫星取 10 次 IMU 采样求平均作为零偏误差，后续数据减去该误差。校准不自动执行，需前端手动触发。

## USB CDC on Boot

每次换固件后需确认 Arduino IDE → Tools → **USB CDC on Boot → Enabled**，否则串口看不到应用输出。
