# 跑步姿态分析平台 — 硬件连接 & 烧录 & 启动指南

> 东北大学大创项目 | 当前版本 V1.1.0 | `hardware-leg-sensors` 分支

---

## 一、系统架构总览

```
┌──────────────────────────────────────────────────────────────────┐
│  3+3 全无线架构（左侧 3 块 S3 + 右侧 3 块 S3，完全镜像）          │
│                                                                  │
│   肘部 S3 ──ESP-NOW──┐                                          │
│   (手臂IMU+鞋垫BLE)    │         ┌──────────┐    BLE    ┌──────┐ │
│                        ├────────→│ 腰间 S3   │─────────→│ PC   │ │
│   大腿 S3 ──ESP-NOW──┘         │ (纯汇聚)   │          │ 桥接器│ │
│   (腿部IMU)                     └──────────┘          └──┬───┘ │
│                                                         │ WS  │
│                                                   ┌──────┴──┐ │
│                                                   │ 浏览器   │ │
│                                                   │ :5502   │ │
│                                                   └─────────┘ │
└──────────────────────────────────────────────────────────────────┘
```

| 位置 | 每侧数量 | 角色 |
|---|---|---|
| 肘部 | 1 | UART×2 读手臂 IMU + BLE Client 连鞋垫，ESP-NOW TX 发给腰间 |
| 大腿 | 1 | UART×2 读腿部 IMU，ESP-NOW TX 发给腰间 |
| 腰间 | 1 | ESP-NOW RX×2 收肘部+大腿数据，组装 V2 RG 包，BLE Server 发给电脑 |

## 二、硬件连接

### 2.1 物料清单

| 物料 | 数量 | 说明 |
|---|---|---|
| ESP32-S3 SuperMini | 6 | 肘×2 + 大腿×2 + 腰×2 |
| JY901S IMU | 8 | 上臂×2 + 下臂×2 + 大腿×2 + 小腿×2 |
| 足部压力鞋垫 | 2 | 左右各一，独立 BLE 外设 |
| 充电宝 | 2 | USB 供腰间 S3 |
| 纽扣锂电池 | 4 | 供肘部+大腿 S3 |
| 弹力绑带 | 6 | 固定各传感器 |
| 腰包 | 2 | 装腰间 S3 + 充电宝 |

### 2.2 肘部 S3 引脚接线

以 RIGHT 为例（LEFT 版大臂/小臂 UART 互换）：

| ESP32 引脚 | 连接对象 | 说明 |
|---|---|---|
| GPIO 1 | OUTPUT LOW | IMU 控制线 |
| GPIO 2 | 上臂 JY901S TX | UART1 RX |
| GPIO 3 | 上臂 JY901S RX | UART1 TX |
| GPIO 4 | OUTPUT HIGH | IMU 控制线 |
| GPIO 9 | OUTPUT LOW | IMU 控制线 |
| GPIO 10 | 下臂 JY901S TX | UART2 RX |
| GPIO 11 | 下臂 JY901S RX | UART2 TX |
| GPIO 12 | OUTPUT HIGH | IMU 控制线 |
| 3V3 | JY901S VCC | 供电 |
| GND | JY901S GND | 共地 |

### 2.3 大腿 S3 引脚接线

| ESP32 引脚 | 连接对象 |
|---|---|
| GPIO 4 | 大腿 JY901S TX (UART1 RX) |
| GPIO 5 | 大腿 JY901S RX (UART1 TX) |
| GPIO 6 | 小腿 JY901S TX (UART2 RX) |
| GPIO 7 | 小腿 JY901S RX (UART2 TX) |
| 3V3 | JY901S VCC |
| GND | JY901S GND |

### 2.4 腰间 S3

- **USB 口接充电宝供电**
- 无传感器接线，纯无线汇聚

### 2.5 足部压力鞋垫 BLE 参数

| 参数 | 左鞋垫 | 右鞋垫 |
|---|---|---|
| MAC 地址 | `FF:24:08:20:53:BD` | `FF:23:10:16:02:EA` |
| Service UUID | `0000fff0-0000-1000-8000-00805f9b34fb` | 同 |
| Notify UUID | `0000fff1-0000-1000-8000-00805f9b34fb` | 同 |

### 2.6 上电顺序（严格按此顺序！）

```
① IMU 传感器通电（JY901S）
② ESP32 上电 → setup() 立即零偏校准（等 IMU 数据，没数据永久卡死）
③ 足部压力鞋垫通电
④ PC 运行一键启动.bat
```

## 三、代码烧录

### 3.1 环境准备

- **Arduino IDE 2.x**（推荐）
- 开发板管理器安装 `esp32 by Espressif Systems`（v2.0.14+）
- 选择开发板：**ESP32S3 Dev Module**
- 所有依赖库（BLEDevice, WiFi, esp_now, HardwareSerial）已内置，无需额外安装

### 3.2 烧录步骤（关键！按顺序操作）

#### 第一步：先烧录腰间 S3，获取 MAC 地址

1. 打开 `rgc-backend/hub-waist/hub-waist.ino`
2. 确认 `#define LEFT` 或 `#define RIGHT` 正确（左侧烧 LEFT，右侧烧 RIGHT）
3. USB 连接腰间 S3 → 选择端口 → 上传
4. 打开**串口监视器（115200 波特率）**，会看到：

```
[RGC] 腰间汇聚器启动
[WIFI] MAC 地址: AA:BB:CC:DD:EE:FF
[INFO] 请将上方 MAC 地址填入肘部和大腿固件的 WAIST_MAC[]
```

5. **记下这个 MAC 地址**，下一步要用

#### 第二步：修改肘部和大腿固件的 MAC 地址

打开 `rgc-backend/rgc-backend.ino` 和 `rgc-backend/satellite-leg/satellite-leg.ino`，找到：

```cpp
// 将 WAIST_MAC 替换为第一步串口打印的腰间 S3 实际 MAC
static const uint8_t WAIST_MAC[] = {0xA0, 0xDD, 0xCC, 0xDD, 0xEE, 0xFF}; // ← 替换
```

改为（示例，填你实际的）：
```cpp
static const uint8_t WAIST_MAC[] = {0xAA, 0xBB, 0xCC, 0xDD, 0xEE, 0xFF};
```

#### 第三步：烧录肘部和腿部固件

| 固件 | 文件 | 烧录次数 | 修改 |
|---|---|---|---|
| 肘部 S3 | `rgc-backend/rgc-backend.ino` | 2 次 (LEFT+RIGHT) | 改 `#define` + 填 MAC |
| 大腿 S3 | `rgc-backend/satellite-leg/satellite-leg.ino` | 2 次 (LEFT+RIGHT) | 改 `#define` + 填 MAC |

每次烧录：
1. 确认 `#define LEFT` / `#define RIGHT` 正确
2. 选择端口 → 上传
3. 串口监视器验证输出正常

#### 第四步：验证

烧录后每块 S3 串口监视器（115200）预期输出：

**肘部 S3**：
```
[RGC] 肘部采集器启动 (ESP-NOW TX)
IMU serial initialized.
upper zero: roll=1.23 pitch=-0.45 yaw=5.67
lower zero: roll=-3.12 pitch=0.89 yaw=10.34
Sensor BLE connected.
Sensor BLE notify enabled.
[ESP-NOW] TX 就绪 → 腰间 S3
```

**大腿 S3**：
```
[RGC] 腿部卫星启动
[RGC] 侧: RIGHT
[UART] 大腿IMU: RX=4 TX=5
[UART] 小腿IMU: RX=6 TX=7
[CAL] 大腿零偏: roll=... pitch=... yaw=...
[CAL] 小腿零偏: roll=... pitch=... yaw=...
[ESP-NOW] 就绪，开始发送数据
```

**腰间 S3**：
```
[RGC] 腰间汇聚器启动
[WIFI] MAC 地址: XX:XX:XX:XX:XX:XX
[ESP-NOW] 收发就绪, 等待肘部+大腿数据...
[BLE] Server 启动: RGC-BLE-RIGHT
[STAT] 肘部数据: 有 (0.1s前) | 腿部数据: 有 (0.1s前)
```

### 3.3 IMU 数据协议

JY901S 通过 UART (115200, 8N1) 发送 11 字节包：

| 偏移 | 长度 | 内容 |
|---|---|---|
| 0 | 1 | 帧头 `0x55` |
| 1 | 1 | 帧头 `0x53` |
| 2-3 | 2 | Roll (int16 LE)，公式: `raw / 32768 × 180` |
| 4-5 | 2 | Pitch |
| 6-7 | 2 | Yaw |
| 8-9 | 2 | 保留 |
| 10 | 1 | 校验和（字节 0~9 累加） |

## 五、数据包格式

### V1（当前臂部固件）— 56 字节

| 字节偏移 | 长度 | 字段 | 说明 |
|---|---|---|---|
| 0-1 | 2 | Magic `RG` | 0x52 0x47 |
| 2 | 1 | Version | 1 |
| 3 | 1 | Payload Len | 48 |
| 4-5 | 2 | Sequence | uint16 LE |
| 6-17 | 12 | 6 角度 | int16×100 ×6 |
| 18-53 | 36 | 18 压力 | uint16 ×18 |
| 54-55 | 2 | Checksum | uint16 LE |

### V2（腰间汇聚）— 68 字节

| 字节偏移 | 长度 | 字段 | 说明 |
|---|---|---|---|
| 0-1 | 2 | Magic `RG` | |
| 2 | 1 | Version | 2 |
| 3 | 1 | Payload Len | 60 |
| 4-5 | 2 | Sequence | |
| 6-17 | 12 | 手臂 6 角度 | 上臂[3]+下臂[3] |
| 18-29 | 12 | 腿部 6 角度 | 大腿[3]+小腿[3] |
| 30-65 | 36 | 18 压力 | |
| 66-67 | 2 | Checksum | |

前端收到统一 30 元素数组：`[手臂6角度, 腿部6角度, 18压力]`

## 六、常见问题排查

| 现象 | 可能原因 | 排查方法 |
|---|---|---|
| 串口监视器卡在 zero error | IMU 没通电/接线错 | 检查 JY901S 供电和 TX/RX 是否反接 |
| 腰间收不到 ESP-NOW 数据 | MAC 地址是占位值没改 | 烧录腰间 S3 → 串口监视器看 MAC → 填入肘部/大腿固件 |
| 桥接器扫不到 BLE 设备 | 腰间 S3 的 BLE Server 没启动 | 看腰间串口是否有 `[BLE] Server 启动` |
| 扫到但连不上 | 距离太远 | ESP32 靠近 PC |
| 连上但无数据包 | 肘部/大腿 ESP-NOW 没连上腰间 | 看腰间串口 `[STAT]` 行是否显示"有" |
| 前端收到数据但图表不动 | CDN 资源加载失败 | F12 → Console 看有无 404 |
| 端口 5502 被占用 | VS Code Live Server | 改 `--http-port` 参数 |
| `ModuleNotFoundError` | Python 多环境混用 | `python -m pip install -r requirements.txt` |
| AI 聊天无回复 | API Key 无效 | 检查 `一键启动.bat` 中的 `DEEPSEEK_API_KEY` |
